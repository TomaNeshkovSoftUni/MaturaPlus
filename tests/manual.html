Режим за ръчно тестване

Настройките важат за този браузър, докато не ги изключите. Отворете формата за обратна връзка в нов таб и опитайте сценариите.

Симулации

Сценарии за Feedback

  1. Без избран тип → грешка до „Тип“.
  2. 9 символа → грешка; 10 символа → приема; 1000 → приема; 1001 → грешка (броячът става червен).
  3. Само интервали → „Въведете текст…“.
  4. Двоен клик / Enter по време на бавна заявка → само един запис (проверете долу).
  5. Грешка при мрежа → текстът остава; повторен опит използва същия requestId.
  6. 6 изпращания за минута → 429 „Твърде много заявки…“.
  7. Презаредете страницата (F5) → записите остават (persistence).
  8. Като гост отворете dashboard/admin.html → пренасочване към вход; API връща 401.
